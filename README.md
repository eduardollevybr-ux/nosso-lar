# Nosso Lar

Aplicativo web para planejar e acompanhar o enxoval de uma casa. As compras são organizadas por cômodo e por loja, com o valor total investido e o que ainda falta comprar.

## O que o app faz

Permite cadastrar cômodos, lojas e itens, registrar cada compra com quantidade e valor e acompanhar tudo em um painel. Um mesmo projeto pode ser compartilhado entre membros, e as alterações aparecem em tempo real para todos.

## Como foi construído

HTML, CSS e JavaScript em uma aplicação de página única. Login, banco de dados e atualização em tempo real com o Supabase. É um PWA: pode ser instalado no celular ou no computador como um aplicativo. A publicação é feita pelo GitHub Pages.

Projeto desenvolvido por Eduardo Levy com apoio de ferramentas de IA generativa.
